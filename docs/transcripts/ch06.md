- **X6-1**（說明用對照，機器不檢查）　C# 的 `TransactionScope` 在程式裡建立交易範圍，呼叫 `Complete` 才會提交。Spring 的 `@Transactional` 註解讓框架在方法前後開始與提交交易。Go 的標準函式庫沒有這兩種機制，交易由程式自己呼叫 `Begin`、`Commit`、`Rollback`。
- **X6-2**（說明用對照，機器不檢查）　PostgreSQL 的 `SELECT ... FOR UPDATE` 會鎖住查到的列，直到交易結束；別的交易要更新或鎖同一列時要等待。
