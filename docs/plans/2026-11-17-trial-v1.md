## 可試用版

- **怎麼起來**：`docker compose up -d --wait`，再照 README 設 `DATABASE_URL`、`REDIS_URL` 後 `go run ./cmd/api`，`curl http://localhost:8080/products`。PowerShell 版指令在 README。
- **試用情境**：
  1. 看影片（使用者自己的成品），每集邊看邊對照 repo：`git checkout epNN` 後照該集腳本的指令跑一次。
  2. ep06 超賣：用 `scripts/k6/oversell.js` 在修好前後各打一次，確認庫存不再被賣超。
  3. 以 C#／Java 觀眾的角度看每集「C# 對照」：標 ＊ 的草案說法準不準、哪裡會被留言抓。
  4. 乾淨 clone 跑 `go test ./...` 與 `go test -tags=integration ./...`，確認觀眾照 README 跑得起來。
  5. 英文頻道：挑一集對照 `docs/scripts/en/` 的英文腳本，看笑點重寫後通不通。
- **資料怎麼重置**：`docker compose down -v`，再從「怎麼起來」重跑；API 啟動時自己套 migration 與種子商品。切回 main：`git checkout main`。
